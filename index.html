❓ 2D ဆိုတာဘာလဲ?

မြန်မာ 2D ဟာ ထိုင်း စတော့အိတ်ချိန်း (SET) Index ကို အခြေခံပါတယ်။ မဲဖောက်ချိန်က မနက်ပိုင်း 12:01 နဲ့ ညနေပိုင်း 16:30 (မြန်မာစံတော်ချိန်၊ တနင်္လာ–သောကြာ) ဖြစ်ပြီး၊ အဲဒီအချိန်က SET Index တန်ဖိုးရဲ့ ဒဿမရှေ့က နောက်ဆုံးဂဏန်း + ဒဿမနောက်က ပထမဂဏန်း ကို ထွက်ဂဏန်းအဖြစ် ယူပါတယ်။

ဥပမာ — SET = 1580.12 ဆိုရင် 2D = 01 ဖြစ်ပါတယ်။

ဒီ site က ရလဒ်တွေကို သတင်းအချက်အလက်အဖြစ်သာ ဖော်ပြတာပါ။ ထီထိုးဖို့ တိုက်တွန်းတာ မဟုတ်ပါ။

❓ မေးလေ့ရှိသောမေးခွန်းများ

2D က ဘယ်အချိန်တွေ ထွက်လဲ?

တနင်္လာနေ့ကနေ သောကြာနေ့အထိ တစ်နေ့ ၂ ကြိမ် — မနက်ပိုင်း 12:01 နဲ့ ညနေပိုင်း 16:30 (မြန်မာစံတော်ချိန်) ထွက်ပါတယ်။

ထွက်ဂဏန်းကို ဘယ်လိုတွက်လဲ?

ထိုင်း SET Index ရဲ့ ဒဿမရှေ့က နောက်ဆုံးဂဏန်း + ဒဿမနောက်က ပထမဂဏန်း ကို ယူပါတယ်။ ဥပမာ SET 1580.12 ဆို 2D = 01 ပါ။ ရလဒ်တိုင်းဘေးမှာ SET တန်ဖိုးပါ ပြထားလို့ ကိုယ်တိုင်စစ်လို့ရပါတယ်။

စနေ၊ တနင်္ဂနွေ ဘာလို့ မထွက်လဲ?

ထိုင်း စတော့စျေးကွက် ပိတ်လို့ SET Index အသစ်မရှိပါဘူး။ ထိုင်းရုံးပိတ်ရက်တွေမှာလည်း ထွက်ဂဏန်း မရှိပါ။

3D က ဘာလဲ?

ထိုင်း အစိုးရထီ (တစ်လ ၂ ကြိမ် — ၁ ရက်နေ့နဲ့ ၁၆ ရက်နေ့) ရဲ့ ပထမဆု ဂဏန်း ၆ လုံးရဲ့ နောက်ဆုံး ၃ လုံး ပါ။

ဒီ site ကနေ ထီထိုးလို့ရလား?

မရပါ။ ဒီ site က ရလဒ်သတင်းအချက်အလက်သက်သက် ဖော်ပြတာပါ။ ထီထိုးခြင်း၊ လောင်းကစားလုပ်ငန်းများ လုံးဝ မလုပ်ပါ။
